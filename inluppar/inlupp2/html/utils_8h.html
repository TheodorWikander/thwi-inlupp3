Detailed Description

Generic utilities: reading validated input from stdin, simple printing and hash/equality functions for use with the hash table.

Knows nothing about the webstore. Functions that read input print the question and ask again until the input passes a check function.

Asks a question and reads lines until check accepts one. The question is printed before every attempt. Lines are limited to 254 characters; longer input is cut. If input ends before an acceptable line was read, an error message is printed to stderr and the program exits, this will leak memory under valgrind.
