\doxysubsection{Detailed Description}
Bussiness logic of the webstore backend\+: merchandise, stock on shelves and carts. Contains no user interface code. 

Ownership\+: The store owns everything it holds. All strings passed into the store are copied, so the callers may free their own strings right after a call. Pointers returned by the store belongs to the store and must never be freed by the caller.

Failiures that depend on user input (invalid merch names, carts etc...) leaves the store unchanged

Violating a \begin{DoxyPrecond}{Precondition}
will crash the program (assert) 
\end{DoxyPrecond}
